After a fire, an insurer asks for a list of everything in your house. Almost nobody has one. EmberProof is a home inventory you actually finish: walk each room with your phone, photograph what matters, and get an itemised, dated, photograph-backed document you can hand an adjuster.

The list nobody has.

Reconstruction from memory is how people lose money they were owed. You end up arguing about a refrigerator model number three weeks after the fact, with no photographs and no receipts, and you get argued down. The fix is boring and takes one afternoon: walk the house and write down one line per thing.

EmberProof makes that afternoon fast, and turns the result into a document that holds up.

What it does

  • Room-by-room capturePhoto first, one line to name it. The rest is optional and out of the way.
  • Estimates that admit they are estimatesLeave the value blank and you get a conservative category figure, marked est. in the report. Overwrite it and it counts as confirmed.
  • A verify screenShows only the guessed values, biggest first, so one sitting turns them into numbers you can defend.
  • A claim-ready PDFCover summary, a table per room with brand, model and serial, and a photograph of every item.
  • Works without a signalA basement or a garage never costs you a photo — captures are held on the device and uploaded when you are back in range.
  • CSV, and a full backupOne ZIP with a consistent database snapshot and every original photo, restorable with one command.

The report.

This is the deliverable. It opens with the numbers that matter — how many items, how many rooms, the total replacement value — and states plainly how much of that total you confirmed yourself versus how much is a category estimate.

That distinction is the whole point. A number you invented is worse than useless in a claim. A number you can defend is worth real money, and this document never blurs the two.

Run it yourself.

Python 3.10 or newer. One command and it is running on your own machine.

git clone https://github.com/ohgeeceee/emberproof
cd emberproof
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py --data-dir ./data

Then open http://127.0.0.1:8787. Or in Docker:

docker build -t emberproof .
docker run -p 8787:8787 -v ~/inventory:/data emberproof
Nothing leaves your machine. No account, no cloud, no upload. The photos you take of the inside of your house stay on the computer you run this on.

What it does not do.

  • No authentication by default. It binds to 127.0.0.1 for exactly that reason; if you expose it, pass --auth-token or put it behind a reverse proxy.
  • Not encrypted at rest. Put the data directory on an encrypted volume — an inventory of your home is a burglary shopping list.
  • The category estimates are conservative guesses, not a valuation. They exist to give you a floor to edit.
  • Single user, single machine. No sync, no accounts, no conflict resolution.
  • HEIC photos (the iPhone default) need one optional package to get thumbnails.
