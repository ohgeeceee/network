Quick Fixes for an Extremely Slow Computer or Laptop

The eight things that actually speed up a slow Windows PC or Mac, in order of effort — from what starts automatically to the drive that is quietly full.

⚡ 30-second fix Difficulty Medium About 30 min Works on Windows · Windows 10 · Windows 11 · macOS Anywhere in the US

The 30-second fix

Restart the computer properly — Start menu, Restart — rather than closing the lid. Then open Task Manager or Activity Monitor and see what is using the most memory. One runaway program is often the whole problem.

If that sorted it, you are done. If not, keep reading — the rest takes about 30 minutes.

Before you start

  • About half an hour
  • The computer plugged in, not on battery
  • Permission to install updates

You do not need to buy more memory yet, and you do not need to reinstall Windows. Work down this list first.

What "slow" usually means

A slow computer is almost never one broken part. It is a handful of small things adding up: too much starting automatically, a nearly-full drive, a program eating all the memory, or a spinning hard disk where a solid-state drive should be.

Work down this list in order. Stop when it feels fast enough — you do not have to do all eight.

The steps

Step 1

Restart it properly

Closing the lid is not a restart. Open the Start menu and choose Restart, or on Mac choose Apple menu > Restart. A real restart clears out the memory that has filled up with weeks of leftover work. If it has been weeks, this alone may be enough.

Step 2

See what is using the most memory

  • Windows: press Ctrl + Shift + Esc for Task Manager, then sort by Memory.
  • Mac: open Activity Monitor from Applications > Utilities, then sort by Memory.

Look for one program sitting near the top that you did not knowingly open. A browser with forty tabs, or a background helper, is a common culprit. Close it and watch the machine breathe.

Step 3

Trim what starts automatically

  • Windows: Task Manager > Startup apps. Turn off anything you do not need running the moment the machine turns on — chat apps, updaters, launchers.
  • Mac: System Settings > General > Login Items. Remove the clutter.

This is the single biggest win for slow startup, and it is completely reversible.

Step 4

Free up disk space

Open Storage settings (Windows: Settings > System > Storage; Mac: Apple menu > System Settings > General > Storage). Empty the Recycle Bin or Trash, clear Downloads, and run Disk Cleanup or Storage Management. Aim for at least 15 percent of the drive free.

Step 5

Update the operating system

Updates are not just security — they fix performance bugs. Let it install and restart. Do this while you make a cup of coffee; it is the slowest step but the easiest.

Step 6

Check for malware and adware

Run a full scan with Windows Security (Windows) or a reputable scanner. Adware is a very common cause of a slow machine — it runs quietly in the background, shows ads, and follows everything you do.

Step 7

Remove programs you do not use

Open the list of installed programs and sort by size or date. Remove the toolbars, the trials you never used, and the "helper" programs that arrived alongside something else. Fewer programs means fewer things running behind your back.

Step 8

Check whether the drive is the problem

If the machine still has a spinning hard disk rather than an SSD, that is your answer, and it is the one upgrade that transforms an old computer. An SSD swap often costs less than a new machine and makes a five-year-old laptop feel new.

Back up your files before anyone opens the case. Drive replacements are routine but they are not risk-free.

When to stop fixing and start replacing

If the computer is more than eight years old, or the processor itself is pegged at 100 percent with nothing running, the honest answer is that it is worn out. An SSD and more memory can buy a few more years — but past a point you are paying to keep an old machine alive. That is a real conversation, and it is fine to have it.

Did it work?

  • The computer starts up in under two minutes
  • Opening a browser and a document no longer freezes
  • The drive has at least 15 percent free space
  • Task Manager shows no single program pinned near 100 percent
Still not working?
  1. Check the drive type. If the computer still has a spinning hard disk rather than an SSD, replacing it with an SSD is the single biggest speed upgrade available and is often cheaper than a new machine.
  2. Run a full malware scan with the built-in tool (Windows Security or a reputable scanner). Adware is a very common cause of a slow machine.
  3. Check for a failing drive: run the manufacturer's health tool. A drive that is dying makes everything slow and is worth catching early.
  4. If it is a work machine or over five years old, weigh the cost of an SSD and more memory against a replacement.

Common questions

How much free space does Windows need?

Keep at least 15 percent of the drive free. Windows uses free space for updates and temporary files, and a drive above 90 percent full will feel slow no matter what else you do.

Will more memory make it faster?

It helps if Task Manager shows memory pinned near the top. If the disk or the processor is the bottleneck, more memory will not help and you would be wasting money.

Does a factory reset fix a slow computer?

Sometimes, but it is a last resort. Work through this list first — a reset wipes your programs and takes hours, and it is often unnecessary.
